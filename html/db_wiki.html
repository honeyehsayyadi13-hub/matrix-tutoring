Database Documentation

This wiki page is for documenting the database. Information is stored in the databases from the website using PHP. The database includes things such as user accounts and consultation requests.

  • Database Name: company_db

  • Connection Method: PHP Data Objects (PDO)

  • System: MySQL

  • Database Table 1: users
  • This table stores user accounts and admin accounts.
  • Columns: id, username, password, active, email

  • Database Table 2: student_progress
  • This table stores the progress of students for admin users.
  • Columns: progress_id, student_name, subject, progress_notes, session_date

  • Database Table 3: service_ratings
  • This table is for users to rate services on the website.
  • Columns: rating_id, service_name, rating, message, submission_date

  • Database Table 4: services
  • This table stores the offered services.
  • Columns: service_id, name

  • Database Table 5: requests
  • This table stores the information of the users who filled out a consultation request form.
  • Columns: request_id, student_name, parent_name, phone, email, message, status, created_at, style, subject, user_id

  • Database Table 6: job_applications
  • This table stores the information of users who filled out a job application form.
  • Columns: application_id, name, phone, email, message, resume_file, created_at

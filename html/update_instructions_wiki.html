Update Instructions Wiki Help Page

This wiki page is for knowing how to update the contents of the images, video, and audio files. For all forms of updates, changes must be pushed to the Github repository here.

  • Images
  • To update the images:
  • 1. Select the image and ensure the name matches the one that must be replaced.
  • 2. Open the "matrix_tutoring" folder.
  • 3. Place the image in the "img" folder, there is also a subfolder called "dark" for icons that are used for the dark mode theme. However, for general images, place them in the img folder.
  • 4. Refresh the webpage.

  • Video
  • To update the video:
  • 1. Select the video that will replace the previous one and ensure the name matches the former one.
  • 2. Open the "matrix_tutoring" folder.
  • 3. Place the video in the "vid" folder.
  • 4. Refresh the webpage.

  • Audio
  • To update the audio:
  • 1. Select the audio file and ensure the name matches the one that must be replaced.
  • 2. Open the "matrix_tutoring" folder.
  • 3. Place the audio file in the "aud" folder.
  • 4. Refresh the webpage.

PHP Documentation

This wiki page is for documenting the PHP files. The PHP files are used for connecting to the database to perform the tasks that require a connection.

  • admin_job_page.php
  • This file is used to display the database of users who have completed a job application form.

  • admin_monitor.php
  • This file is used for the admin to monitor the databases.

  • admin_ratings.php
  • This file displays the ratings of the services to admin users from the database.

  • admin_requests.php
  • This file is used to display the database of users who have completed a consultation request form.

  • admin_services.php
  • This file enables admin users to edit the names of the services offered through the database.

  • admin_users.php
  • This file is used for admin to see the information of the users who have an account on the website through the database. Admin users can disable accounts as well.

  • Auth.php
  • This file is used for the sign up and log in systems. It also creates hashed passwords for security purposes.

  • coding_page.php, college_university.php, english_page.php, essay_page.php, exam_test_page.php, french_page.php, geography_page.php, history_page.php, homework_page.php, learning_page.php, math_page.php, reading_writing_page.php, robotics_page.php, science_page.php, STEM_page.php, summer_learning_page.php
  • These files are for users to see what services we offer including a description of each. Users can rate the service from 1 to 5 stars and include a message for feedback.

  • company_login.php
  • This file's purpose is to create a distinguished log in page for company users. It uses Auth.php to perform the necessary tasks for admin users to log in.

  • company_page.php
  • This file is used as a menu page for company users. It is created in mind for having access to pages to perform admin only actions such as disabling accounts and monitoring the databases.

  • dbcon.php
  • This file is used to create a PDO connection to be called upon on the PHP files that require a connection to the MySQL database.

  • delete_request.php
  • This file deletes consultation requests from the database. It is used in the admin_requests.php file to delete consultations.

  • edit_service.php
  • This file is a PHP page that enables admin users to change a name of a service. To access this page, the user must be in the admin_services.php page and select the edit option on one of the services.

  • form.php
  • This file is the dynamic consultation form page where users can fill out a consultation request which is sent to the admin.

  • job_page.php
  • This file is used as a dynamic form for users to fill out job application forms in the website. These forms are sent to the admin.

  • logout.php
  • This file enables users to log out of their accounts, both regular users and admin users.

  • process_job.php
  • This file is used to process job appliation form submissions. It also uploads the resumes to the uploads folder and stores the information into the database which in turn is displayed for admin users to see.

  • process.php
  • This file is used to process consultation request forms and sends the information to the database. The information can be seen from the admin side.

  • profile.php
  • When a user is logged into their account, they are sent to this page where they can see options as buttons to either log out or to be sent to the consultation page to fill out a consultation request form.

  • register.php
  • This file is a separate user account registration page and user log in page for regular users so they are separate from company users.

  • save_progress.php
  • This file saves the entries of the progress of students submitted by company users through the database.

  • student_progress.php
  • This file displays the student progress submissions made by company users on a separate page.

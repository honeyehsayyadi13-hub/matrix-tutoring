How to Install

  1. You must ensure you have the following: a web browser, PHP, MySQL, Apache Web Server and AMPPS

  2. Download the project folder "matrix_tutoring" from GithHub click here for the link, and place it into the www directory in the Ampps folder.

  3. Open AMPPS program to start Apache and MySQL. Ensure that they are running to proceed.

  4. Open phpMyAdmin. It will run if AMPPS is running Apache and MySQL.

  5. In phpMyAdmin, create a database with the name "company_db"

  6. Select the newly made database and click "Import". Then choose the SQL file in the "matrix_tutoring" folder. Then click "Go".

  7. Go into the "dbcon.php" file and change the connection information (database name, username, password, and host) based off of your MySQL localhost user information and save the file.

  8. Next, in a browser, go to "http://localhost/matrix_tutoring/index.html" to be sent to the home page.

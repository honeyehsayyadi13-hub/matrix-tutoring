Admin Login and Navigation

A guide for logging in as admin

  1. Open the Matrix Tutoring homepage, or click here.

  2. Use the navigation bar to find the following: "Company Account", or click here.

  3. Fill in the following to log into an admin account: username, and password (the only way company accounts can be made is through the database for security reasons).

  4. When done filling out the form, select the "Log In" button.

  5. After a successful log in, the user will be sent to the company home page where they can navigate the following through the navigation bar: home, job applications, consultation requests, monitoring, ratings, student progress, manage users, or change themes.

A guide for admin navigation

  1. After logging in, the user is sent to the home page with a navigation bar.

  2. The home page enables users to either log out or add a students name, a subject, and what they did that day. This information can be saved by pressing the "Save Progress" button. To access this information, click the "student progress" link in the navigation bar.

  3. When selecting "Job Applications", users are sent to a page where they can see a table with every person who submitted a job application and the information they filled out as well.

  4. If "Consultation Requests" is chosen, users are sent to a page with a table of every consultation request made along with the according information. From here, users can delete these requests.

  5. In the navigation bar, if "Monitoring" is selected, the user can see monitoring information.

  6. If a user chooses "Ratings" in the navigation bar, they will be able to see user feedback submitted on the website and the statistics of the company's ratings.

  7. When selecting "Student Progress", users can see what information has been created about students.

  8. The "Manage Users" link in the navigation bar enables admin to get a table of the users on the website and see the status of their account. From here, admin can disable accounts.

  9. The "Manage Services" option in the navigation bar allows the admin to see what services are offered in the database. When clicking the "Edit" link, users are taken to a page where they can change the names to replace what is offered and this will be saved and updated automatically in the database.

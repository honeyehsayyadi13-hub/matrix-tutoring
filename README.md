# matrix-tutoring
Matrix Tutoring is a full-stack website created for a project assignment. The website is designed for a fake tutoring company. Some of the features include a sign-up and log-in system for parents, as well as a log-in system for the admin and workers of the company. Depending on which title a user logs in under, there are unique features.

This website can be run using AMPPS and by uploading the database to MySQL to set up the system correctly.

The default admin login information is the following: username=admin, password=1234. As for parent login, the user can sign up with a username and password of their choice.
